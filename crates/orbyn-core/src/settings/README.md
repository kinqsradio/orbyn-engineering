# Settings

The person's settings and what the environment says about itself.

| Module | Owns |
| --- | --- |
| `preferences` | Settings beyond `ServerSettings`, with defaults and project overrides |
| `keybindings` | Built-in keybindings with the person's file over them |
| `environment` | The theme and release channel the environment publishes |

The crate's [group table](../../README.md#groups) lists every group.
